## autovacc.lua
Faithful port of RijiN's auto vaccinator cheat with many improvements and bug fixes.\
Currently supports:
1. Manual charging (use R to cycle resistances and press right click to pop selected resistance)
2. Passive mode (only pop on instant kill danger e.g crit rockets)
3. Pop on 'Activate Charge' with option to automatically pick best resistance to pop
4. Disallow resistances (never pop blast, for example)
5. Not placebo sensitivity settings (RijiN made them only apply in dev mode)
